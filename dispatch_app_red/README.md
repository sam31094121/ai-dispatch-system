# 兆櫃 AI 派單公告系統｜全線解鎖優化版

本系統已於 2026/05/04 完成全面更新，目前處於「全線解鎖優化」狀態，支援智慧數據同步與多維度業績核算。

## 核心營運規則 (動態優化)
本系統排名遵循「AI 比例原則」，並支援即時審計與人工智慧修正：
**合併 -> 審計 -> 計算 -> 排序 -> 發佈**

### 1. 權重計分 (10,000 分制)
- **實收總業績**：3,000 分 (權重 30%)
- **追續單金額**：2,500 分 (權重 25%)
- **全部總業績**：1,500 分 (權重 15%)
- **追續客單價**：1,500 分 (權重 15%)
- **追續單數量**：1,500 分 (權重 15%)

### 2. 六層過濾鐵律 (Tie-break Rule)
同分情況下，依序比對：權重總分、實收金額、續單金額、總業績、客單價、續單數。

### 3. 派單分級
- **🔴 A1**：第 1-4 名 (核心主力)
- **🟠 A2**：第 5-11 名 (次主力)
- **🟡 B組**：第 12-18 名 (一般量單)
- **🟢 C組**：第 19 名以後 (補位觀察)
