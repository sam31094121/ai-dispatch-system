# AI比例原則永久鎖死版

本系統固定用於「當日結算業績輸入後，自動產出正式派單順序」。

## 計算主軸

每位行銷人員依全員最高值換算比例分數，再加總成正式權重分數，滿分 10000 分。

## 權重

| 欄位 | 權重 |
| --- | ---: |
| 實收總業績 | 3000 |
| 追續單金額 | 2500 |
| 全部總金額 | 1500 |
| 追續客單價 | 1500 |
| 追續單數量 | 1500 |

## 欄位定義

- 實收總業績：當日各平台整合後的實收總金額。
- 追續單金額：當日各平台整合後的追續單金額。
- 全部總金額：當日各平台整合後的全部總業績。
- 追續客單價：追續單金額 / 追續單數量。
- 追續單數量：當日各平台整合後的追續單成交數。

## 公式

單項分數 = 某人該項數值 / 全員該項最高值 * 該項權重

正式權重分數 =

```text
(實收總業績 / 全員最高實收總業績 * 3000)
+ (追續單金額 / 全員最高追續單金額 * 2500)
+ (全部總金額 / 全員最高全部總金額 * 1500)
+ (追續客單價 / 全員最高追續客單價 * 1500)
+ (追續單數量 / 全員最高追續單數量 * 1500)
```

## 防呆

- 全員最高值為 0 時，該項所有人分數一律記 0。
- 追續單數量為 0 時，追續客單價一律記 0。
- 不可出現除以 0、NaN、Infinity。
- 已離職只列審計，不進正式排名。
- 不得人工手改排名。

## 正式排序

1. 正式權重分數，高到低
2. 實收總業績，高到低
3. 追續單金額，高到低
4. 全部總金額，高到低
5. 追續客單價，高到低
6. 追續單數量，高到低

## 派單分級

- A1：第 1-4 名。
- A2：第 5-11 名。
- B 組：第 12-18 名。
- C 組：第 19 名以後。

## 流程

輸入三平台當日業績後，系統必須自動完成：

```text
合併 -> 審計 -> 計算 -> 排序 -> 輸出
```

不得改公式，不得改權重，不得跳步，不得混用別套排名規則。
