Money Rain Assets
=================

Place realistic, transparent-background money sprites in this folder.

Supported coin filenames:
- maple-coin-front.png
- maple-coin-angle.png
- maple-coin-side.png
- maple-coin-front.webp
- maple-coin-angle.webp
- maple-coin-side.webp

Supported bill filenames:
- dollar-bill-front.png
- dollar-bill-angle.png
- dollar-bill-folded.png
- dollar-bill-front.webp
- dollar-bill-angle.webp
- dollar-bill-folded.webp

Recommended specs:
- Transparent PNG or WebP.
- Coin images: 512x512 or larger, real metal lighting, visible thickness/edge.
- Bill images: prop or safe dollar-style bills only, 900px wide or larger, angled/folded variants.
- Avoid full counterfeit-ready U.S. banknote scans. Use safe prop/stage-money style or edited/blurred details for web animation.

The Official Dispatch Lock card automatically loads these assets when present.
If no assets exist, it falls back to generated placeholder sprites.
